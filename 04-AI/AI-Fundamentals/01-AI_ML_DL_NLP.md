# AI Day 1: AI, ML, Deep Learning, NLP and LLM

*My learning notes, written in simple language.*

---

## 1. Artificial Intelligence (AI)

**Simulation of human intelligence by machines.**

Components of AI:
- Machine Learning
- Deep Learning
- NLP (Natural Language Processing)
- Computer Vision
- Robotics

---

## 2. Machine Learning (ML)

A **subset of AI** where machines **learn patterns from data** without being explicitly programmed.

### Types of ML

| # | Type | Data | Idea |
|---|------|------|------|
| 1 | Supervised | Labeled data | Learns from examples with answers |
| 2 | Unsupervised | Unlabeled data | Finds hidden patterns on its own |
| 3 | Reinforcement | No fixed data, uses feedback | Reward-based learning |

---

## 3. Deep Learning (DL)

A **specialized type of ML** that uses **neural networks** to learn complex patterns automatically, especially from images, speech, and text.

**Example architectures:** CNN, RNN, Transformers

---

## 4. NLP (Natural Language Processing)

AI technology that enables machines to **understand, interpret, and generate human language**.

**Applications:**
- Chatbots
- Translation
- Sentiment analysis
- Text summarization

---

## 5. AI vs ML vs DL (Quick View)

| Term | In one word | What it does |
|------|-------------|--------------|
| **AI** | Thinks | Makes machines intelligent, can use rules to solve problems |
| **ML** | Learns | Learns from data and examples, subset of AI |
| **DL** | Learns deeply | Learns complex patterns automatically using neural networks, subset of ML |

```
AI
 └── Machine Learning
      └── Deep Learning
           └── LLMs (built on Transformers)
```

---


## Quick Revision

- AI = machines acting intelligent
- ML = AI that learns from data
- DL = ML using neural networks
- NLP = AI that works with human language
- LLM = Deep Learning model (Transformer) trained on huge text data
- Key capability = in-context learning
